# 食序管家 6.1.5 体重记录实施计划

> **执行要求：** 逐项使用测试先行；每个行为先观察失败，再写最小实现。不得修改已发布迁移 001–014，不得连接线上数据库。

**目标：** 在 0.6.1 稳定基线上增加独立 `diet_weight` 领域，按系统时间记录体重与可选自由状态，并返回 7 日均值及与前 7 日窗口的趋势。

**架构：** TypeScript 只负责严格公共 schema、工具注册和桥接；Python
`body_weight.py` 负责单位归一、事务化 CRUD、精确平均和趋势；SQLite 迁移 015
保存整数克。修改与删除沿用工作流句柄和资源版本，撤销/重做沿用事务快照。

**技术栈：** TypeScript、TypeBox、Vitest、Python 3.11+、pytest、SQLite、OpenClaw
Tool Plugin SDK。
