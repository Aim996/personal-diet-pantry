# 开发依赖风险接受记录

本记录覆盖 v0.7.5.3 构建环境中的精确开发依赖
`openclaw@2026.7.1-2`。安装包只声明 `openclaw >=2026.5.17` 为 peer
dependency，不携带这个开发依赖、它的传递依赖或 `node_modules`。
`npm audit --omit=dev --audit-level=high` 的生产依赖结果必须为 0 项漏洞。

2026-08-04 的审计确认：稳定版 OpenClaw 随包携带自己的
`npm-shrinkwrap.json`，根项目的 npm `overrides` 无法替换其内部的精确
依赖。当前修复仅存在于 `2026.7.2-beta.7`，因此本版本不为消除审计
告警而切换到 beta 测试宿主。机器清单改为逐条接受稳定版子树中的公告，
统一复审截止到 2026-09-03；稳定版一旦发布修复即应移除对应记录。

可由根项目真正修复的 `nanoid`、`postcss` 和 `protobufjs` 已分别固定到
`3.3.17`、`8.5.23` 和 `7.6.5`，所以它们不在风险接受清单中。版本契约同时校验 override
与锁文件，防止只改声明而未更新实际解析版本。

隔离依据如下：

- 所有接受路径都位于 `node_modules/openclaw/node_modules/`；
- `openclaw@2026.7.1-2` 仅用于开发期宿主 Schema 和插件兼容测试；
- `npm pack` 白名单及安装包端到端测试证明这些路径不会进入安装包；
- 生产依赖审计独立执行且必须为 0 项漏洞；
- 完整审计必须与机器清单中的公告、包名、级别和路径逐项匹配；
- 未登记、过期、路径漂移或已经消失但未删除的记录都会阻断发布。

机器可读权威位于 `contracts/dependency-risk-acceptance.json`；本文只提供
审阅说明。
