## 删除

只删除经过字符化测试证明已经被深模块替代的重复实现：

- `SKILL.md` 中已迁入 reference 且不属于主导航的长例子和重复规则；
- 手写动作清单中可由 `contracts/tools.yaml` 确定生成的副本。

不得删除：

- 001–015 任一已发布迁移；
- v0.6.1.5.1 的兼容动作；
- 体重正式领域或其自然口语规则；
- 用户数据、软路由目录或现有发布目录。

## 指向调整

- `src/index.ts`、Python `ACTIONS`、正式变更动作集合、公共行为表和工具文档均指向 `contracts/tools.yaml` 的同一动作事实。
- 主 `SKILL.md` 只指向 `references/` 中的细节，不再复制完整行为章节。
- 成本、浪费和趋势查询只从正式 SQLite 事实实时计算，不增加第二套指标事实。
- 导入只接受 v0.6.7 定义的版本化导出包；备份恢复仍走独立维护路径。
- 发布构建只从干净 Git 提交生成，不读取 `dataDir`。
