推送 `v0.7.4.28` 后触发了 [Verified Release 工作流](https://github.com/Aim996/personal-diet-pantry/actions/runs/31161584233)，但 GitHub 在运行任何 workflow step 前返回账户账单锁定：`verify-build` 没有启动，`publish` 被跳过。

因此，本次不能写成“GitHub CI 通过”。在用户明确授权创建 Release、最终 main/tag/manifest 提交一致、本地完整门禁通过、候选目录不可变且哈希已核对的前提下，维护者按发布设计中的人工回退路径创建 Release，只上传构建器产生的五个资产，并使用已提交的 `RELEASE.zh-CN.md` 作为正文。
