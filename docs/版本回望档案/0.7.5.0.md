## 为什么值得修改

未发布的 `0.7.5` 候选虽然解决了一批确认循环，但把越来越多日常口语固化成正则路由和精确调用指令。它能通过已知句式，却会让智能体在换一种自然说法时失去判断，也会让每次修复都扩大规则耦合。v0.7.5.0 因此不再继续补正向句式，而是明确三层职责：Skill 给业务路标和证据要求，智能体判断普通正向意图，插件只守查询、否定、未来、他人、破坏性动作、跨域部分提交和重复失败等安全边界。

## 本版范围

- 删除运行时正向短语路由器 `direct-write-policy`；
- 普通正向输入进入 `agent_directed`，智能体可以选择安全的新增或预览能力；
- 第一次非只读选择后，插件把本轮锁定到已选领域与动作，避免后续工具游移；
- 烹饪＋进食＋剩菜、删除、修改、系统设置和维护继续使用受保护契约；
- `SKILL.md` 改为目标、能力地图、证据层级、安全边界和正式回执合同；
- 产品/技术版本统一为 `0.7.5.0 / 0.9.1`；
- 不新增数据库能力，不修改 v0.7.4.28、未发布 `0.7.5` 或错误命名的 `0.7.5.1` 目录。
