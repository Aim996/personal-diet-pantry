## 为什么值得开发

真实 OpenClaw 口语测试证明四个问题具有共同的业务阻断价值：目标方案没有可提交凭证导致二次确认；固体食物含水污染饮水；真实已过期库存被日期校验拒绝；多项入库会并发争抢同一 SQLite。它们都能在业务或桥接层稳定复现，不需要为单句话增加专用脚本。

## 唯一范围

- 为目标方案增加可重放安全的一次确认工作流；
- 以“明确饮用体积”区分营养饮料与固体食物含水；
- 允许用户事实来源的过去到期日入库，同时保留推荐硬过滤；
- 按 `dataDir` 串行正式写入；
- 给刚完成摄入补充不追问钟点的通用时间证据，不指定唯一工具路线。
