## 实际实现

- 工具回调优先沿用提示阶段捕获的稳定会话身份，临时 `sessionId` 不再覆盖同一轮凭证作用域；唯一餐食纠正可直接命中上一条成功操作。
- `nutrition_estimate` 接受部分营养事实，纤维、钠和食物含水等未知字段保持未知，不伪造为零；饮水累计边界未改变。
- Skill 明确把“家里实际还有某物”识别为库存事实；过期只改变安全状态与推荐资格，不取消库存事实。
- 安装文档要求 Docker 前台 Gateway 的 PID 或启动时间真实变化后，才能宣称运行时已换新。

## 已知缺口

- 自动化不能替代目标 OpenClaw 模型的自然语言选路，六条口语化阻断场景仍待实机验证。
- OpenClaw WebUI 新会话状态问题继续按 `UI-01` 独立处理，不归因给本 Skill。

## 值得继承与不得照搬

- 值得继承：`0.7.5.3` 的玉米直接记录、纯水短回执、推荐过期硬过滤、同库写入串行化和六项双行回执。
- 不得照搬：纠正二次确认、未知纤维导致的调用循环、过期库存只提醒不入账，以及“安装成功即认为运行时已更新”的部署假设。
