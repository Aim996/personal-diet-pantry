## 为什么值得修改

公开仓库已存在，但首页仍描述为 Private/发布准备中，且远端没有实际 Release。普通用户和其他智能体无法取得可验证安装包，现有安装提示词也无法完成。修复这项事实断裂能直接让项目从“可阅读源码”变成“可安全安装”，不需要触碰运行时业务行为。

## 允许变化

- Release workflow 的当前版本参数。
- 对应版本/文档/构建/发布合同测试。
- 正式 Git Tag 与 GitHub Release。
