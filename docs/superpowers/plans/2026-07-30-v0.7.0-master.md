# 食序管家 v0.7.0 Master Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留七个顶层工具和稳定旧核心的前提下，交付一个通过数据可信度、真实 Skill 行为、菜谱—购物—入库闭环和发布门禁的完整 v0.7.0。

**Architecture:** 以 `TrustedWorkflowModule`、`FoodDecisionModule` 和 `SkillBehaviorContract` 三个稳定 seam 收口复杂度。`service.py` 继续作为兼容编排器，但新增规则进入对应深 module；最终通过一份总门禁发布，不单独发布任何中间波次。

**Tech Stack:** Python 3.11–3.13、SQLite、pytest 8、TypeScript 5.9、TypeBox 1.1、Vitest 3、Node.js 22.22.3+、OpenClaw 2026.5.17+、PowerShell CI。

## Global Constraints

- 正式版本统一为 `0.7.0`；开发过程中不得发布 `0.7.0-partial`、`0.7.0-dev` 或功能不完整的安装包。
- 保持 `diet_meal`、`diet_water`、`diet_weight`、`diet_pantry`、`diet_transaction`、`diet_report`、`diet_system` 七个顶层工具名称不变。
- SQLite 业务表是正式事实源；Markdown、导出、报告和 metric snapshot 都是派生物。
- Python 运行范围保持 `>=3.11,<4`；Node.js 下限保持 `>=22.22.3`；OpenClaw peer 下限保持 `>=2026.5.17`。
- 不新增运行时依赖，除非现有标准库、PyYAML 和 tzdata 无法满足已确认规格，并先补依赖风险说明。
- 所有业务修复使用 RED → GREEN → REFACTOR；禁止先改实现后补测试。
- 不在开发阶段安装、重启、配置或覆盖软路由上的 OpenClaw。
- 不重写稳定的餐食、饮水、体重和库存主线；只在本次触及的 seam 深化。
- 所有时间事实以 UTC 保存，以 profile timezone 查询、分桶和展示；禁止根据模型猜时区。
- 所有货币按 currency 分开；禁止隐式汇率换算。
- 任何不可逆操作都必须有精确 preview、live handle、锁内复核和公开回执。
- 任何成功 undo 都必须有 `effect_count > 0`。
- 任何用户可见回复都不得包含 SQL、内部 action 名、绝对路径、stack trace、凭据或调试置信度。
- 正式发布必须从干净 Git 提交构建，源码包和安装包分别重复构建两次并核对成员清单与哈希。
- 候选冻结前必须完成定点代码复审；只要仍有 P0/P1，就必须修复并提交、重跑全部门禁、再次复审，直到同一干净提交无未解决 P0/P1。
- IR6 冻结候选后不得再产生任何 tracked correction 或 tracked commit；若发现必须修改的受跟踪文件，当前候选、真实渠道证据、签名和发布产物全部作废，并从 IR6 候选冻结链重新开始。

function Resolve-SafeRunFile {
    param(
        [Parameter(Mandatory = $true)][string]$Path,
        [Parameter(Mandatory = $true)][string]$Label
    )
    $Resolved = (Resolve-Path -LiteralPath $Path).Path
    $Item = Get-Item -LiteralPath $Resolved -Force
    if ($Item.PSIsContainer -or
        ($Item.Attributes -band [IO.FileAttributes]::ReparsePoint) -ne 0 -or
        -not $Resolved.StartsWith(
            $RunPrefix,
            [StringComparison]::OrdinalIgnoreCase
