# 食序管家 v0.7.4.28 可供智能体安装的公开 Release 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变运行时业务行为和 migrations 001–021 的前提下，把公开仓库发布为可由普通 OpenClaw 用户或其他智能体安全安装、核验、更新和回滚的正式 `v0.7.4.28` GitHub Release。

**Architecture:** Release-first 分发；GitHub Release 的 `installable.tgz` 是唯一普通安装入口，SHA256SUMS 与 manifest 提供供应链证据。README/安装手册/AI 提示词共享同一安装状态机。所有业务行为继续由现有 Schema、服务端与 Skill 约束，发布层不得修改它们。

**Tech Stack:** Markdown、Git/GitHub CLI、GitHub Actions YAML、Python 3.11+、Node.js 22.22.3+、pytest、Vitest、OpenClaw npm-pack。
